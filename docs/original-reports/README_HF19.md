# Makai-Mura WonderSwan EN-US — HF19

Versión de desarrollo, no RC. HF19 traduce el aviso de borrado de información de enemigos y conserva la trayectoria acumulativa HF1–HF18. Se aplica `patches/Makaimura_EN_US_Phase4W_HF19_CUMULATIVE_FROM_JP.bps` **directamente** a la ROM japonesa de 2 MiB y SHA-256 `ac0c793b30d2de19ff6504d5a205e33f42aeeac724e7c284b48f48fbfbe53ed8`. No se aplica sobre HF18.

Windows: `BUILD_HF19.bat CLEAN_JP.ws`. macOS/Linux: `./build_hf19.command CLEAN_JP.ws`. Ambos crean una ROM privada en el equipo que ejecuta el build y un BPS acumulativo. Este paquete contiene fuentes, informes, evidencia gráfica JP/HF18/HF19, hashes y parche; no distribuye ROM ni BIOS.
